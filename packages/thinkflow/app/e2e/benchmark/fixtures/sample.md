# ThinkFlow 产品说明

## 核心功能

**ThinkFlow** 是一个可视化 AI 内容创作工作流工具，基于节点画布设计。

### 输入节点类型
1. **文本** - 直接输入文字内容
2. **链接** - 传入 URL，由 Agent 抓取内容
3. **文件** - 上传文档，自动转为 Markdown
4. **记忆** - 从记忆库选取已有内容
5. **信息流** - 接入 MCP 工具（Fetch / GitHub）

### 输出平台
- 知乎长文
- 公众号图文
- 日记/笔记
- 小红书图文
