## ✨ 什么是 design.md？

简单说，它就是你和 AI 之间的「设计翻译官」。

就像你给装修师傅看效果图，而不是只说「装得好看点」—— `design.md` 就是把你的审美标准，翻译成 AI 能精准执行的「设计图纸」。

它是一个 Markdown 文件，里面定义了：

- 🎨 **配色方案**（主色、辅助色、语义色）
- 🔤 **字体规范**（标题、正文、注释的层级）
- 📐 **间距系统**（8px 基础网格、圆角规则）
- 🧩 **组件库**（按钮、卡片、表单长什么样）
- 📱 **响应式规则**（手机、平板、桌面怎么适配）

---

## 🚀 为什么它比「口头描述」强 10 倍？

| 方式                  | 结果                       |
| --------------------- | -------------------------- |
| ❌ "要简洁现代风"     | 每次生成都不一样，像开盲盒 |
| ❌ "参考某大厂风格"   | AI 理解偏差，四不像        |
| ✅ **一份 design.md** | 每次输出稳定、统一、可控   |

**核心优势：**

1. **一致性** —— 100 个页面，100 次生成，风格零偏差
2. **可复用** —— 一个文件，多个项目直接套用
3. **省token** —— 不用每次重复描述设计风格
4. **团队协作** —— 设计师写一遍，所有 AI 工具都能读

## 📝 一份实用的 design.md 长什么样？

以下是我实战总结的精简模板，复制就能用：

```markdown
# Design System

## Colors

- Primary: #3B82F6 (蓝色，主按钮、链接)
- Secondary: #10B981 (绿色，成功状态)
- Danger: #EF4444 (红色，错误提示)
- Background: #F8FAFC (浅灰，页面底色)
- Surface: #FFFFFF (纯白，卡片背景)
- Text Primary: #1E293B (深蓝灰，标题)
- Text Secondary: #64748B (中灰，辅助文字)

## Typography

- Font Family: Inter, system-ui, sans-serif
- H1: 32px, bold, tracking-tight
- H2: 24px, semibold
- Body: 16px, regular, line-height 1.6
- Caption: 14px, medium, Text Secondary

## Spacing

- Base unit: 8px
- Section gap: 48px
- Card padding: 24px
- Button padding: 12px 24px

## Components

### Button

- Primary: 蓝色填充，白色文字，圆角 8px
- Secondary: 白色填充，蓝色边框，蓝色文字
- Ghost: 透明背景，hover 时浅蓝底色

### Card

- 白色背景，1px 浅灰边框
- 圆角 12px，阴影 sm
- 内边距 24px

### Input

- 高度 44px，圆角 8px
- Focus 状态：蓝色边框，蓝色阴影
- Error 状态：红色边框，红色提示文字
```

## 💡 三个让 AI 秒懂的技巧

### 1️⃣ 用「具体数值」代替「形容词」

❌ "间距大一些"  
✅ "卡片间距 24px，组件间距 16px"

### 2️⃣ 给出「状态变化」规则

不只是描述默认样式，还要说明：

- Hover 怎么变？
- Focus 怎么变？
- Disabled 怎么变？
- Loading 怎么变？

### 3️⃣ 附一张「参考截图」

在 design.md 同级目录放一张你想要的界面截图，AI 能结合文字 + 视觉参考，理解更精准。

## 🛠️ 实战：5 分钟搭建你的 design.md

**Step 1：打开你最爱的 AI 工具**

Lovable、v0、Cursor 都支持。

**Step 2：创建 `design.md` 文件**

放在项目根目录，和 `README.md` 同级。

**Step 3：复制上面的模板，改改颜色和字体**

根据你的品牌色调整数值，5 分钟搞定。

**Step 4：告诉 AI：「请遵循 design.md 的设计规范」**

然后你会发现——

**AI 突然开窍了！** 🎉

生成的界面开始有「设计体系」的味道，不再像东拼西凑的。

## 🎯 进阶玩法

### 多主题切换

准备 `design-light.md` 和 `design-dark.md`，一键切换明暗主题。

### 组件级细化

针对表格、图表、弹窗等复杂组件，单独写设计规范。

### 设计 tokens

把颜色、间距抽成变量，方便全局替换：

```
--color-primary: #3B82F6;
--spacing-md: 16px;
--radius-lg: 12px;
```

## 💬 写在最后

用好 `design.md`，本质上是在做一件事：

> **把「审美」变成「规则」，把「感觉」变成「代码」。**

当你给了它一份靠谱的设计说明书，它回馈你的，就是一个专业级的设计系统。
